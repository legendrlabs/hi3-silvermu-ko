# 확인된 원본 데이터 소스

이 프로젝트는 원본 JSON을 저장소에 복제하지 않고, 사용자가 silvermu.top에서 직접 불러온 화면에 번역 레이어만 적용합니다.

| 카테고리 | 원본 데이터 |
| --- | --- |
| 캐릭터 | `/data/db/bh3/characters.json` |
| 무기 | `/data/db/bh3/weapons.json` |
| 성흔 | `/data/db/bh3/stigmata.json` |
| 협동자/인형 | `/data/db/bh3/elfs.json` |
| 아이템 | `/data/db/bh3/materials.json` |
| 임무 | `/data/db/bh3/tasks.json` |
| 심연 | `/data/db/bh3/abyss.json` |
| 기억 전장 | `/data/db/bh3/battlefield.json` |
| 상점 | `/data/db/bh3/shops.json` |
| CG | `/data/db/bh3/cg.json` |
| 게임 용어 사전 | `/data/db/bh3/dictionary.json` |
| 기능 설정 | `/data/config.json` |
| 게임 목록 | `/data/games.json` |

## 정책

- 원본 JSON, 이미지, JS를 이 저장소에 복제하지 않습니다.
- 한국어 번역 코드와 번역 사전만 저장소에서 관리합니다.
- 고유명사는 공식 한국어 표기가 확인된 경우를 우선합니다.
- 미확인 고유명사는 원문을 유지합니다.
