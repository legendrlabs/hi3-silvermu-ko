silvermu HI3 한국어 패치

silvermu.top의 붕괴3rd 데이터베이스를 한국어로 표시하는 비공식 커뮤니티 번역 레이어입니다. 원본 사이트 코드·이미지·게임 데이터를 재배포하지 않습니다.

설치

  1. Tampermonkey 또는 호환 사용자스크립트 관리자를 설치합니다.
  2. 아래 설치 버튼을 누릅니다.
  3. https://silvermu.top/database/hi3.html을 새로고침합니다.

사용자스크립트 설치

v0.2.0 진단

원본 사이트에서 남아 있는 중국어와 동적 데이터 경로를 수집할 수 있습니다. 페이지 우측 아래 KO 버튼을 우클릭하면 진단 보고서가 클립보드에 복사됩니다. 복사한 내용을 프로젝트 Issue 또는 ChatGPT에 붙여넣어 주세요.

번역 정책

확인되지 않은 고유명사를 임의 번역하지 않습니다. 붕괴3rd 한국 서비스에 공식 명칭이 있는 경우 그 표기를 우선하며, 미번역 문자열은 원문을 유지합니다.

프로젝트 성격

본 프로젝트는 팬 제작 비공식 번역 도구이며 silvermu.top 또는 HoYoverse/miHoYo의 공식 프로젝트가 아닙니다. 원본 사이트의 콘텐츠와 게임 관련 상표·저작물의 권리는 각 권리자에게 있습니다.
